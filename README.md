# Decore — Premium Flowers & Event Decorations

Luxury flower studio and event decoration platform for Ethiopia.

## Tech Stack

- Next.js 15+ (App Router)
- TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion
- Three.js / React Three Fiber
- Supabase (Auth, DB, Storage, Realtime)
- React Hook Form + Zod
- Lucide Icons
- Vercel

## Features

- Cinematic 3D hero with interactive flowers
- Design gallery with filters & lightbox
- Custom flower design builder
- Event decoration booking system
- Full e-commerce order flow
- Customer dashboard
- Admin dashboard with analytics
- Ethiopia-specific (ETB, cities, Telebirr/CBE ready)
- Realtime order tracking
- Secure RLS policies

## Getting Started

```bash
npm install
cp .env.example .env.local
# Fill Supabase keys
npm run dev
```
